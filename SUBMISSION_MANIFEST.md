# Submission manifest

The evaluator package contains the ten Turkish Markdown/DOCX/PDF deliverables, the PowerPoint and PDF presentation, the five-minute demo script, the mail-ready email draft, source and submission ZIP files, release readiness notes and SHA-256 checksums.

Canonical repository: <https://github.com/eyupilis/sharp-screenshot-view>

Release commit and CI run are recorded in the generated release readiness document. No `.env`, credentials, `node_modules`, cache, coverage or build output is included in either ZIP.
